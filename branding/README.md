# Capture Automator identity

A mint camera frame, cut-out play symbol and warm gold capture light on forest green. The mark represents capture and replay without small lettering.

The SVG is the editable master. Android uses matching vector foreground, background, monochrome and notification resources. Adaptive icons use a 108dp layer and keep the mark inside the centred 66dp safe region, for launcher masks. Android 13+ has an explicit monochrome themed-icon layer. See [Android adaptive icon guidance](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive).

0.6.2-dev changes branding and version metadata. Capture, verification, batch and preset behaviour remains as in 0.6.1. Existing permissions are unchanged.
