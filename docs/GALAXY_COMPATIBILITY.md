# Using the touch recorder on Galaxy phones and tablets

For the first run, open the target app full-screen on the built-in display. Pick the orientation, navigation style and taskbar setting you intend to use. Record a short local-save preset, replay it, and check the reported media count. Record or calibrate a separate copy for a different device, folded state, orientation or window size. Existing presets are kept when installing a matching-signature update.

Samsung supports gesture and button navigation, including changes to navigation button order. Galaxy tablets and supported Z Fold main displays can show a taskbar. The recorder uses Android-reported system insets on Android 11 and newer to determine the usable area. A same-app dialog can reuse the established full-screen coordinate frame only while the safe area matches. A visible second application or split divider invalidates that cached frame. Android 10 retains the older inset estimation. A floating window or a popup drawn inside another app can be indistinguishable from ordinary app content. Use full-screen recording for the most predictable result.

The new recording screen scrolls in landscape. Name, selected package, media expectations and filter survive activity recreation during setup. Start stays outside the scrolling list.

Batch playback opens Android Recents. It looks for a unique supported Close all control and can activate its clickable parent when only the child carries the label. A launcher that does not expose a recognised control reports cleanup unavailable. Samsung Keep open, system tasks and launcher-specific policies can affect cleanup.

The app requires Android 10 or later and the visible Accessibility service. External-display DeX, cross-hinge gestures, simultaneous touches, individual Galaxy firmware versions and non-English cleanup labels have not been certified. This build does not include a Samsung-specific camera adapter. Record the actual shutter, mode and save taps on the target device.
